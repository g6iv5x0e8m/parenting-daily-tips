# 结石术后，这条“猪尾巴管”令人害怕！“无管化”不再谈管色变

> 更新时间：2026-09-17 (UTC+8)

**泌尿结石**是泌尿系的常见病，泌尿结石的患者常常有腰痛、血尿、排尿时疼痛难忍的症状，给生活带来诸多不便，大大降低生活质量。

在临床上，**输尿管镜碎石或经皮肾镜碎石术**是泌尿结石的治疗方法之一，术后，医生一般会在患者体内常规留置**双“J”管**或**肾造痿管**用于内支架引流。

对于做过结石手术的患者而言，往往会谈“管”色变，这是因为**体内滞留的双“J”管可能导致置管后并发症，出现尿频、尿急、尿痛、血尿等症状。**很多结石患者在第一次术后出现结石复发，却因为害怕再次置管而拒绝手术。

**术后是不是一定要置管？未必！**近日，广州医科大学附属第三医院泌尿外科为一位右肾结石复发的患者实施了取石手术，术后实现了**“无管化”**，不放置肾造瘘管或双J管，有效避免了置管后并发症，术后第二天即顺利出院。

**医学指导**

广州医科大学附属第三医院泌尿外科副主任医师 **邹自灏**

1

//

**置管痛苦大，**

**男子结石复发谈“管”色变？**

两年前，小梁（化名）在体检中发现右输尿管结石，在外院做了输尿管镜钬激光碎石取石术，术中在体内留置了双“J”管，俗称“猪尾巴管”，用来做内支架引流。

但这条“猪尾巴管”让小梁直呼**“痛不欲生”**！严重的置管后的并发症让小梁开始尿频、尿急、尿痛及血尿，直到术后一个月拔除双“J”管后上述症状才得以缓解。

小梁体内的“猪尾巴管”

然而好景不长，没多久，结石又找上了门。今年，小梁在体检中又发现了右肾结石，大小为2.4*1*1.5cm3，来到广州医科大学附属第三医院就医，泌尿外科副主任医师邹自灏详细查看分析了小梁的病情和相关检测报告，计划给他做微创经皮肾镜碎石手术治疗。一听到要手术，小梁有一个强烈的要求：“医生，能不能术后不要置管！”

“综合考虑结石的实际情况和小梁的强烈愿望，我们为他制定了**个体化手术方案**。”邹主任介绍说，“**通过小通道微创经皮肾镜钬激光碎石取石手术顺利取出了结石**，由于术中出血少，结石清除干净，术后可以不用停留肾造瘘及双J管。这次手术**既处理了小梁的结石问题，又满足了小梁不放管的心愿**”。术后小梁恢复良好，第二天就顺利出院了。

2

//

**取石术后“无管化”，**

**减轻病人负担**

所谓**“无管化”**，即结石术后**不放置肾造瘘管或双J管，或者两者都不放**。

**不放置肾造痿管的好处**

避免了其意外牵拉引起的术后大出血，明显减轻患者疼痛，减少患者的感染风险、住院时间和住院费用；

**不放置双”J”管的好处**

可避免患者置管后出现尿频、尿急、血尿等症状，还免去了术后拔除双“J”管的过程，减轻患者身心和经济负担。

邹自灏主任介绍，无管化虽好，但不是每个结石术后病人都能做到，它有**严格的适应症：**

1

术中无明显结石残留，无需再次手术；

2

术中无严重出血，术后无活动性出血；

3

术前、术中无明显感染；

4

术中肾脏没有穿孔及严重的尿外渗；

5

输尿管没有损伤和阻塞。

无管化的经皮肾镜取石手术更符合术后快速康复的理念，在严格把握适应症的情况下，无管化的经皮肾镜取石**手术效果良好，术后恢复快、美观、更加微创，而且安全可行。**有泌尿系结石困扰的朋友们不要再谈“管”色变了！

3

//

**泌尿系结石危害大，**

**切忌胡乱应对**

**结石潜在危害大，**

**能否排出因人而异**

网上流传着一些结石应对偏方，比如跳绳、喝醋等，这些方法真的可以帮助结石排出吗？

邹自灏主任介绍，因为结石的成分、大小、形状因人而异，**不是每个结石都可以自然排出的。**

一般来说，**6mm以下**，形状为椭圆形，表面比较光滑的肾结石、输尿管结石，在泌尿科医生的专业指导下，通过**口服止痛药、大量饮水、口服排石药物、加强运动**等方式是可以自行排出的。

但是**6mm以上**的泌尿系结石就不那么好对付了。通常上尿路结石的排出过程是：肾脏产生尿液，尿液把结石冲出肾脏，进入输尿管。结石随着输尿管自上而下的自滤活动不断向下排。但是，输尿管有三个狭窄的位置，很容易把比较大的结石卡住，导致**肾内压升高**，出现**肾绞痛**的症状。有些患者痛感不明显，但结石卡住的时间比较长，会造成**肾积液，肾内压越来越高****，导致皮质慢慢被压薄，损伤肾脏功能。**

邹主任提醒，泌尿系结石虽然很常见，但**处理不当有可能会引发严重并发症**，包括感染、梗阻等，严重者会造成**肾功能受损甚至丧失。**

因此，检查发现有泌尿系结石或出现肾绞痛症状的患者，**不要因为害怕手术而耽误治疗，更不要听信网上那些所谓偏方胡乱处理**，以免造成不可挽回的后果。

**震波碎石效果好，**

**仍需严格把握指**

除了听信偏方，很多结石患者还倾向于体外震波碎石治疗。邹主任介绍，体外震波碎石是一种安全有效的结石治疗手段，但它仍需要严格把握指征，才能达到较好的碎石效果：

**①结石不能太大**，要＜2cm，避免碎石后形成石街，造成严重梗阻和感染；

**②结石不能太硬**，碎石前最好要先通过CT检查，如果结石的CT值越高代表结石越硬，CT值＞1000Hu的结石不建议做碎石；

**③肾结石碎石效果最好**，因为肾脏产生尿液，碎石的冲击波要在液体里才能产生比较好的效果；

**④同一个部位的肾结石体外碎石不建议超过两次。**碎石的冲击波对肾脏毛细血管有一定的破坏作用，所以很多患者碎石后会排血尿，如果碎石次数过多，会导致以后发生肾脏萎缩的可能；

**⑤两次碎石之间的间隔要7-10天。**

邹自灏建议，应对结石，大家首先到医院要做超声或者CT检查，对体内的结石进行详细评估，然后再明确下一步治疗计划，考虑能否进行体外震波碎石、是否需要手术、术后是否需要置管等。

4

//

**预防结石，**

**可先从饮食入手**

很多结石的病人，尤其是泌尿结石，复发几率很高，因此，应对结石，尽早预防才是关键！为了不与结石相见，可以先从饮食入手：

**1. 适量饮水**

水份可以降低尿液中形成结石物质的浓度，减少晶体沉积，也有利于微小结石排出。建议每天**饮水量在2000-2500ml左右**。天气炎热时和运动之后要适当增加饮水量。**尽量喝白开水**，少喝碳酸饮料、高糖饮料，另外还有**避免过多饮用浓茶、咖啡**等。

**2. 合理膳食**

常见的泌尿系结石成分有草酸钙、磷酸钙、尿酸盐等，由于成分不同，饮食也不能一概而论，总的来说，大家可以多吃一些低**钠、低蛋白及低嘌呤的食物**。平常也可以喝点**柠檬水**，因为柠檬中含有能抑制结石形成的枸橼酸，对预防尿路结石有一定的作用。

针对不同类型的泌尿系结石，可以**针对性地进行饮食调节：**

- 
**低草酸饮食：**少吃高草酸的食物，比如菠菜、四季豆、芦笋、苋菜等。

- 
**低尿酸饮食：**避免高嘌呤食物如动物内脏、带壳海鲜等，少喝啤酒和含糖饮料。
