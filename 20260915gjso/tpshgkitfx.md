# 你知道吗？胰激肽原酶肠溶片有这些作用

> 更新时间：2026-09-15 (UTC+8)

😩前段时间有个患者是扶着墙进来的，我一看，这可不得了，赶紧把他扶到椅子上坐着。了解后才知道，这位患者几年前就被查出有乙肝，虽然在吃药控制，但断断续续也不规律。结果前几天开始没力气，吃不下饭，他也不当回事，以为过段时间就好了。直到就诊的那天上午，他右边肋下也开始疼痛，这才重视起来，赶紧打车来医院。

我说你心可真大啊，有乙肝不好好吃药就算了，出现症状也不知道第一时间往肝脏方面想，就跟下雨了还不知道打伞一样。

🔎哎，吐槽归吐槽，我还是第一时间让他去完善肝功能、乙肝五项、腹部B超等检查。等检查结果出来后，果然是乙肝引起的这些症状，甚至还发展到了肝淤血，好在情况还算不严重，否则再晚点来可能就要住院了！

我给他开了一些药，除了常规的抗乙肝病毒药，还特意加了一个药——胰激肽原酶肠溶片。可能有朋友要问了，这个病人就是乙肝引起的这些症状，为什么要开胰激肽原酶肠溶片？有什么用呢？

💡可能这位朋友并不了解胰激肽原酶肠溶片在我们肝病科的应用，就让我来详细介绍一下吧！

✅扩张血管：比如说针对刚刚这位患者的肝淤血，胰激肽原酶肠溶片可以使肝脏血管松弛，从而扩张血管，改善肝淤血的情况。特别是肝脏中有很多微小血管，这种情况就更适合使用胰激肽原酶肠溶片，可以加快血液流动，从而促进物质代谢，维持正常的肝脏功能。

✅降低血液粘滞度：对于已经出现肝淤血的患者，局部血液粘滞度较高，也就是血液比较粘稠，对于血液流动和物质交换都会产生巨大障碍，随着时间推移，体内毒素就会堆积，并且会促进血栓形成，如果堵塞血管，还可能造成严重后果。而胰激肽原酶可以激活体内的一种纤溶酶，它能够溶解血液中的纤维物质，降低血液的粘稠度，预防血栓形成。

✅减少炎性反应：以刚刚那位乙肝患者为例，由于他不按医嘱吃药，肝炎控制较差，长期的慢性炎症反应就会导致肝脏长期处于充血、水肿状态，肝功能也会逐渐下降。而研究表明胰激肽原酶可以抑制多种炎性因子的合成和释放，也就是可以减轻肝脏的炎症反应，延缓肝脏损伤。
